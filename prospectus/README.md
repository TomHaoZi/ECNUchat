# ECNUchat, Inc. — Preliminary Prospectus （招股说明书草案）

![ECNUchat logo](logo-full.png)

`ECNUchat-Prospectus.pdf` — a preliminary prospectus (Form S-1 style, "red herring"
format) for a proposed initial public offering of ECNUchat, Inc. Class A common
stock and a proposed listing on the Nasdaq Global Market under the symbol **ECNC**.

Contents: prospectus summary, risk factors, use of proceeds, capitalization and
dilution, MD&A, a detailed Business section covering the platform's post-quantum
hybrid cryptography (PQXDH with ML-KEM-768, hybrid Double Ratchet, signed
hash-chained group state), industry overview, management, description of capital
stock, underwriting, and the index to financial statements. 44 pages.

**Status:** preliminary draft ("Subject to Completion"). All offering amounts,
prices and financial figures are shown as bracketed placeholders `[•]`, exactly as
in a real preliminary prospectus before pricing; the financial-statements section
is a framework to be completed with audited statements. This document is a draft
prepared for discussion purposes — it is not an offer to sell securities, and no
registration statement has become effective.

- `logo-mark.png` / `logo-full.png` — the ECNUchat logo (chat bubble + keyhole:
  messaging + encryption), drawn for this project.
- `source/` — the document generator (Python + ReportLab) and logo script, so the
  prospectus can be revised and rebuilt.
