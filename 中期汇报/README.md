# ECNUchat 中期汇报材料

密码学课程项目 ECNUchat（《基于 ECDH 与 AES-GCM 的端到端加密聊天室》）的中期汇报全套材料。汇报人：钟浩；小组成员：钟浩、吴泽霖、陈俊伟、陈俊桥。

| 文件 | 是什么 |
|---|---|
| `ECNUchat-中期汇报.pptx` | 汇报 PPT（23 页：正文 17 页 + 图解 6 页；简约大字版，图文并茂，每页带演讲备注，汇报到谢谢页结束） |
| `ECNUchat-中期汇报-预览.pdf` | PPT 的 PDF 预览版，手机上可直接看 |
| `ECNUchat-中期汇报-讲稿.md` | 详解版讲稿：逐页讲什么、名词的人话解释、每页可能被追问的问题，附逐页逐字稿（照着念版，约 11 分钟） |
| `ECNUchat-答辩问答准备.md` | 答辩题库（36 题）：49 个专业名词直白解释速查表 + 每题【先说人话】【标准回答】【可能追问】三层 |
| `ECNUchat-队友速通手册.md` | 完全详细白话版：寄信比喻讲清整个项目 + 一条消息的一生 + 必背三段话 + 36 题（一句话版 + 完整人话版）+ 答辩保命守则 |
| `ECNUchat-答辩问答-网状导图.html` | 网状思维导图（网页，浏览器打开）：中心 → 5 个分组 → 36 题层层展开，点题看一句话版 + 完整版详解，虚线是题与题之间的关联，下方附全部 36 题完整清单，可打印 |
| `ECNUchat-答辩问答-动态网状图.html` | 动态网状图（网页，浏览器打开）：会动的力导向布局，中心 → 5 分组 → 36 题 → 49 个名词共 91 个节点、183 条连线，可拖拽 / 缩放 / 全屏，点节点看详解；下方附 36 题清单与 49 名词全表 |
| `ECNUchat-中期汇报-速记卡.md` | 上台前速记卡：每页时间点、最难五问的一句话答法、演示命令 |
| `配图/` | PPT 里 6 张图解的原图（架构、密钥体系、握手时序、双棘轮、群组、指纹） |

**队友使用顺序**：先看《队友速通手册》第二节（寄信比喻）和第三节（背三段话），再用《答辩问答准备》练题；主讲对着讲稿和 PPT 备注排练。
